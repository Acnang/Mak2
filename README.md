# 블록웨이브 — 3D 블록 샌드박스 MVP

Three.js 기반의 브라우저 3D 블록 샌드박스 초기 버전입니다. PC와 터치 기기를 지원하도록 구성했습니다.

## 실행 기능
- 3D 복셀 지형과 간단한 절차적 높낮이
- 나무, 모래 지형, 광석이 포함된 월드 생성
- PC 키보드/마우스와 모바일 터치 조작
- 플레이어 이동, 점프, 중력, 블록 충돌
- 블록 채굴 및 설치
- 9칸 핫바와 블록 선택 창
- 브라우저 localStorage 자동 저장
- JSON 월드 백업 내보내기
- 청크 단위 메시 생성 및 수정 청크 갱신

## 로컬 실행
ES Modules를 사용하므로 `index.html`을 파일 탐색기에서 직접 열지 마세요. 아래 중 하나를 사용하세요.
- VS Code의 Live Server 확장
- Python이 설치된 환경에서 저장소 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속

게임은 Three.js를 CDN에서 가져오므로 실행 시 인터넷 연결이 필요합니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다.
2. `index.html`, `css`, `js`, `README.md`를 저장소 루트에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 선택하고 저장합니다.
6. 배포가 완료되면 Pages 화면에 표시되는 URL로 접속합니다.

## 조작
### PC
- `W A S D`: 이동
- `Space`: 점프
- `Shift`: 달리기
- 마우스 이동: 시점 회전 (게임 화면 클릭 후)
- 좌클릭: 조준한 블록 채굴
- 우클릭: 조준한 블록 면에 블록 설치
- `1`~`9`: 핫바 선택
- `E`: 블록 선택 창
- `Esc`: 일시정지

### 모바일 / 태블릿
- 왼쪽 가상 조이스틱: 이동
- 오른쪽 게임 화면 드래그: 시점 회전
- 채굴 / 설치 / 점프 버튼: 해당 동작
- 블록 선택: 블록 선택 창 열기

## 현재 MVP의 한계
이 버전은 기반 게임 플레이를 확인하기 위한 초기 버전입니다. 전체 청크 스트리밍, 정교한 텍스처 아틀라스, 인벤토리 수량/제작, 몬스터, 체력·배고픔, IndexedDB 월드 목록, 물리적인 수영 등은 아직 포함하지 않았습니다. 자동 저장은 현재 브라우저의 localStorage에 월드 블록 데이터를 저장합니다. GitHub Pages 배포 후 실제 PC와 여러 모바일 기기에서 별도 테스트가 필요합니다.
